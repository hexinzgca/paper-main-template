# Asset provenance and size justifications

No research figures are included yet. `assets/README.md` is documentation only.

For each final figure, record its exact `assets/...` path, producing experiment
commit, code commit actually used, configuration/run ID, input checksums,
command and working directory, output SHA-256, and any post-processing.

For a file at least 2,000,000 bytes, add a path-specific explanation of why
compression or an alternative format would lose necessary information. This does
not waive the 10,000,000-byte Git blob ceiling.

The automatic check confirms a large asset path is mentioned here. A reviewer
must still judge the explanation and the scientific provenance; mentioning a path
alone does not establish valid justification.
