# Tylina / 本地文件同步检查

Git 管理历史和子模块指针。Tylina 按项目设计用于论文编辑与同步，
但此模板没有假设你的版本具备某个 ignore 文件名、设置路径或 API。
**本文件是人工检查单，不是可导入的 Tylina 配置。**

启用整个论文目录的文件同步前，在实际客户端确认 `.git`（目录或文件）、
`submodules/`、`build/` 均不被同步，且不会跟随符号链接进入这些目录。
不要把 `submodules/` 写进 Git 的 `.gitignore` 作为替代。

无法确认排除支持时，不要启用整个仓库的文件同步；先使用 Git 传输。
切换分支、恢复依赖或准备发布时暂停并发写入，完成后重新检查 Git 状态。

人工记录：客户端/版本、设备、日期、实际排除设置、验证方式、确认人。
当前状态：**NOT VERIFIED**。远端 CI 无法认证协作者设备上的本地设置。
